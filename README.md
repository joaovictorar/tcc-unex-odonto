# Site Assistente Odonto - Unex V9 - Áudio Final Corrigido

Esta versão corrige o áudio de verdade.

## Correções

- O áudio não é mais chamado duas vezes ao mesmo tempo.
- Cada tela usa uma única fila de fala.
- A assistente fala a frase principal e depois todas as opções.
- A fala não corta ao entrar na tela de datas.
- O botão de repetir áudio fala tudo de novo.
- Mantém o visual da versão V6/V7.

## Importante

Por regra do navegador, nenhum site consegue tocar áudio sozinho antes do primeiro toque do usuário.
Por isso a tela "TOQUE AQUI" continua necessária.
Depois desse primeiro toque, o site fala automaticamente todas as telas.
